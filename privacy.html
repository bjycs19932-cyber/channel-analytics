개인정보처리방침 — 채널 성과 수집

시행일: 2026-10-05

수집하는 정보

사용자가 승인한 YouTube 채널의 분석 데이터(영상별 조회수, 시청 시간, 평균 시청률, 시청 유지율, 좋아요·공유·댓글 수, 구독자 증가)와 채널 ID·영상 제목만 읽습니다.

이용 목적

채널 운영자 본인의 콘텐츠 성과 분석에만 사용합니다.

저장과 공유

데이터와 인증 토큰은 사용자 본인의 컴퓨터에만 저장되며, 제3자에게 판매·공유·전송하지 않습니다. 광고나 다른 목적에 사용하지 않습니다.

권한 철회

언제든지 Google 계정 → 서드파티 앱 액세스에서 이 앱의 권한을 삭제할 수 있습니다. 로컬에 저장된 파일도 직접 삭제할 수 있습니다.

Google API 서비스 사용자 데이터 정책

이 앱의 Google API 데이터 사용은 제한적 사용 요건을 포함한 Google API Services User Data Policy를 준수합니다. YouTube API 서비스를 사용하며 YouTube 서비스 약관과 Google 개인정보처리방침이 적용됩니다.

English summary

This app reads only the authorizing owner's YouTube Analytics data, read-only. Data and tokens stay on the owner's own computer and are never sold, shared or transferred. Access can be revoked at any time at myaccount.google.com/permissions.
